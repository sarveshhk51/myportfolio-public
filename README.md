# Sarvesh Kuber Portfolio

A modern, animation-focused personal portfolio website for **Sarvesh Kuber**, built with React and Vite.

## Highlights

- Responsive single-page portfolio with project detail routes
- Framer Motion animations and interactive transitions
- GSAP-powered visual effects
- Three.js / React Three Fiber support
- Tailwind CSS with reusable UI components
- Project showcase with detailed case-study style pages
- Experience, skills, certifications, extracurriculars, and contact sections
- Responsive navigation with scroll-spy behavior
- Static assets for project documentation and portfolio visuals

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- GSAP
- Three.js / React Three Fiber
- React Router
- Radix UI
- TanStack Query
- Lucide React
- Vitest

## Getting Started

### Prerequisites

- Node.js 18+
- npm, pnpm, yarn, or Bun

### Install

```bash
npm install
```

### Development

```bash
npm run dev
```

The Vite development server will print the local URL in the terminal.

### Production Build

```bash
npm run build
```

### Preview the Production Build

```bash
npm run preview
```

### Tests

```bash
npm run test
```

### Lint

```bash
npm run lint
```
